## 交付范围

- HTML、CSS、原生 JavaScript，解压后用 Chrome 打开 index.html，无构建和联网依赖。
- 发布寻物/招领 → 浏览或关键词搜索 → 同一记录的详情 → 查看/复制联系方式 → 发布者确认完成。
- 保留绿色、米白色和八页原型的信息层次，扩展为响应式桌面网页。
- 加分项：分类和地点组合筛选、复制联系方式、自动保存草稿、可选物品图片。
- 本地数据持久化，明确演示数据与实际发布；示例发布者的记录不可由当前用户修改。
- 自动化白盒单元测试不少于 10 个，覆盖权限、状态、校验、检索和存储异常。
- README、测试教程/报告、流程图、截图、两份博客稿、提交核对清单。

## 技术约定和边界

模块按业务规则（core.js）、存储（store.js）、示例（seed.js）、界面（app.js）拆分；普通 script 顺序加载，避免 file:// 下模块/fetch 的限制。业务规则可在 Node.js 中直接导入进行测试。动态文本统一转义；状态从类型和完成标记派生；写入成功后才展示成功结果。

纯静态版本的数据属于当前浏览器，不提供跨设备实时共享或真实身份认证。此限制写入产品帮助、README 和博客，不将本地演示描述为校园线上服务。使用另一浏览器或清理数据会改变本地身份。生产上线需要服务端身份鉴权和数据库。
